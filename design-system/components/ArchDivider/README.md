# ArchDivider

Fascia decorativa di archi a altezze sfalsate, ripresa dal packaging: separa l'hero dal menù o chiude la pagina sopra il footer.

Usa solo i colori `brand-*` (fissi tra i temi). Il consumatore sceglie numero di archi (6–10) e altezze; nessun testo sopra. È decorativa: `aria-hidden="true"`.

Una sola fascia per pagina.
