# Badge

Etichetta breve sotto una voce del menù: numero di pezzi, piccante, vegetariano, novità.

- `ds-badge--pz` per i pezzi («8 pz.», «2 pz.»), come scritto nel menù.
- `ds-badge--spicy` (shoyu) per i piatti «leggermente piccanti» o con salsa spicy.
- `ds-badge--veg` (wasabi) per vegetariano; `ds-badge--new` (arancio-ink su arancio-soft); `ds-badge--info` (cobalto) per note come «Senza glutine».

Il significato è sempre nella parola, mai solo nel colore. Massimo tre badge per voce.
