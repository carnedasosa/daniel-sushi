# Announcement

Riquadro per gli avvisi che oggi escono come post Instagram: aperture straordinarie, giorni di chiusura, festività.

- Cobalto (`ds-announce`) per avvisi informativi; arancio (`ds-announce--arancio`) per inviti ad ordinare.
- Il consumatore fornisce occhiello, titolo (corto, MAIUSCOLO via CSS) e una o due frasi. Nessuna immagine obbligatoria; un'illustrazione dei post può stare accanto.
- Uno solo per pagina, in cima alla home sotto l'header. Togli l'avviso quando non è più valido.
