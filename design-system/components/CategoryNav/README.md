# CategoryNav

Barra di chip per saltare tra le categorie del menù; scorre in orizzontale su mobile e resta fissa in alto sotto l'header.

Il consumatore fornisce l'elenco delle categorie con i nomi del menù reale (Tartare, Sashimi, Starter, Sushi Gio, Hosomaki, Nigiri, Triangolini, Uramaki, Special roll, Poke bowl, Box, Primi, Dessert, Beverage) e segna quella visibile con `aria-current="true"` (fondo `sumi`, testo `riso`).

Ogni chip è un vero link ad un'ancora, alto almeno `tap`.
