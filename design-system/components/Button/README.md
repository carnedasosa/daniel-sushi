# Button

Comando a pillola per le azioni del sito: ordinare, aprire il menù, arrivare al locale.

- **Primario** (`ds-btn ds-btn--primary`): riempimento `arancio`, testo `on-arancio`. Uno solo per schermata, di solito «Ordina ora».
- **Secondario** (`ds-btn--secondary`): bordo `linea-forte`, testo `sumi`. Per «Sfoglia il menù», «Scarica il menù PDF».
- **Link** (`ds-btn--link`): testo `cobalto` sottolineato, per azioni minori.

Il consumatore fornisce l'etichetta (verbo all'imperativo, dando del tu) e un vero `<a href>` o `<button>`. Altezza minima `tap`. Focus: anello `focus` 2px con 2px di distacco.

Non usare testo bianco sull'arancio e non affiancare due primari.
